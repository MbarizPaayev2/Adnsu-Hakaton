Satış məsləhətçisi
Füzuli, Şərur, İmişli, Biləsuvar, Şamaxı,Bakı üzrə

Vəzifə və öhdəliklər:

- Ünsiyyətcil, təşəbbüskar;

- Komandada işləmək bacarığı;

- Müştərilərlə işləmək qabiliyyəti;

- İşdə dəqiqlik və detallara fikir vermə qabiliyyəti; 

- Tapşırıqların vaxtında, dəqiq yerinə yetirilməsi;

 

Tələblər:

- Yaş: 23 yaş və yuxarı;

- Orta təhsil. Ali təhsil arzuolunandır;

- Azərbaycanca səlis danışıq;

- Satış üzrə minimum 1 il iş təcrübəsi ( Mobil telefon və elektronika sahəsində təcrübə üstünlükdür)
